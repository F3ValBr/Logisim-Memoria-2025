# Uso del sistema

`LogisimCL` es un proyecto que extiende e incorpora nuevas funcionalidades al `Logisim` original. Por ello, gran parte de 
la documentación existente mantiene la misma estructura y lineamientos respecto a cómo realizar diversos procesos dentro del simulador.

En el contexto de este proyecto, el enfoque se centrará en describir y explicar el uso de las nuevas capacidades introducidas 
por `LogisimCL`, complementando la documentación tradicional cuando sea necesario. A continuación se señalan las funcionalidades a abordar:

* [Importador de `SystemVerilog`](howtoverilog.md)
